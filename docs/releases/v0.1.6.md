# v0.1.6 — GPT-5.6 native agent migration

## 개요

Agmo의 네이티브 에이전트가 역할별 GPT-5.6 모델 티어를 사용하도록 업데이트했습니다. 기존 역할 분리, `modelClass`, `posture`, reasoning effort는 유지했으며, 모델 라우팅 변경과 함께 SSOT에서 벗어나 있던 체크인 prompt 및 agent TOML 미러를 다시 동기화했습니다.

## 주요 변경

- 계획, 구현, 검증, 설계, 비평 역할을 `gpt-5.5`에서 `gpt-5.6-sol`로 전환했습니다.
- 지식 검색과 durable note 합성 역할을 `gpt-5.4-mini`에서 `gpt-5.6-terra`로 전환했습니다.
- 빠른 저장소 탐색 역할을 `gpt-5.3-codex-spark`에서 `gpt-5.6-luna`로 전환했습니다.
- 에이전트 SSOT, 프로젝트에 설치된 네이티브 에이전트 TOML, 테스트 기대값, README 모델 표를 동기화했습니다.
- planner, executor, critic의 체크인된 prompt 및 agent TOML 미러를 기존 prompt SSOT와 동기화했습니다.
- package, CLI, plugin package, plugin manifest, README 버전을 `0.1.6`으로 동기화했습니다.

## 호환성과 운영 참고

- 모델 마이그레이션 과정에서 source prompt의 의미는 변경하지 않았으며, 기존 SSOT와 달랐던 체크인 미러만 동기화했습니다. 에이전트 이름, 역할, `modelClass`, `posture`, reasoning effort도 그대로 유지했습니다.
- 기존 사용자는 업데이트 후 `agmo agents sync --scope project`를 실행해 프로젝트의 `.codex/agents`를 새 모델 정의로 동기화할 수 있습니다.
- 이번 변경은 모델 라우팅 업데이트이며 공개 CLI 명령이나 설정 스키마에는 breaking change가 없습니다.
