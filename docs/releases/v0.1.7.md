# v0.1.7 — GPT-6 Astra and hook reliability

## 개요

Agmo의 계획·구현·검증·설계·비평 에이전트를 `gpt-6-astra`로 전환하고, 계획·설계·비평 역할의 reasoning effort를 `xhigh`로 높였습니다. 동시에 중복 설치 훅의 단일 실행, 세션 상태의 동시 쓰기 안전성, 검토 의도 라우팅, 긴 도구 입력의 위험 검사를 보강했습니다.

## 주요 변경

- `agmo-planner`, `agmo-executor`, `agmo-verifier`, `agmo-architect`, `agmo-critic`을 `gpt-6-astra`로 전환했습니다.
- planner, architect, critic의 reasoning effort를 `xhigh`로 설정하고 라우트 권장 effort가 에이전트 정의를 직접 따르도록 했습니다.
- 세션별 파일 잠금과 원자적 JSON 교체로 여러 훅 프로세스의 상태 갱신 손실을 방지했습니다.
- 프로젝트·사용자 훅 명령에 설치 범위를 기록하고, 두 설치가 겹칠 때 적용 가능한 프로젝트 훅만 실행 소유권을 갖도록 했습니다.
- 코드 검토 요청을 읽기 전용 `code-review` 경로로 보내면서 실제 수정 명령과 부정·보고 전용 표현을 구분합니다.
- PreToolUse가 저장용 요약을 자르기 전에 전체 입력을 검사하도록 변경해 긴 명령 끝의 위험 패턴도 감지합니다.
- package, CLI, plugin package, plugin manifest, README 버전을 `0.1.7`로 동기화했습니다.

## 호환성과 운영 참고

- 설치 범위 기반 훅 중복 방지는 프로젝트와 사용자 훅을 모두 새 버전으로 동기화한 뒤 보장됩니다. 마이그레이션 중 기존 unscoped 직접 호출은 계속 실행됩니다.
- 세션 잠금의 소유권이 손상되거나 확인되지 않으면 제한 시간 후 진단과 함께 실패합니다. 소유 프로세스가 종료됐음을 확인한 뒤에만 잠금을 수동 제거해야 합니다.
- `agmo-wisdom`은 `gpt-5.6-terra`/`medium`, `agmo-explore`는 `gpt-5.6-luna`/`low`를 유지합니다.
- 공개 명령이나 설정의 breaking change는 없습니다.
